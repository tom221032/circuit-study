# 电路 · 学习站（邱关源《电路》第六版 × 石群 80 讲）

把 B 站合集 [BV1jHLGzDEJe](https://www.bilibili.com/video/BV1jHLGzDEJe/)
（石群主讲 · 邱关源《电路》第六版 · 80 集 4K 修复版）和本地的
《邱关源〈电路〉（第 6 版）笔记和课后习题（含考研真题）详解》PDF 拼成一个可以按章学习、
按句跳转视频、能全文搜索字幕与笔记的本地网站。

每一章的「复习笔记」里还夹着**从 80 集视频里提炼出来的知识点卡片**（结论 / 推论 / 注意 / 公式 / 技巧），
每张卡片都带「第 N 集 mm:ss ↗」，点一下就能跳到老师讲这句话的地方。

纯静态站点（HTML + CSS + 原生 JS，无构建、无需联网的第三方服务；公式排版用本地内置的 KaTeX），
数据由 `scripts/` 下的 Python 脚本生成。

## 在线版

已经部署到 GitHub Pages：**https://tom221032.github.io/circuit-study/**

仓库：https://github.com/tom221032/circuit-study


脚本走 GitHub 的设备码登录（device flow，申请范围只有 `public_repo`），
打印 8 位验证码后在 https://github.com/login/device 输入即可；已授权过的话
可以直接 `set GITHUB_TOKEN=xxx && python scripts\deploy_github.py` 跳过这一步。
之后它会自动建仓库、推送、开启 Pages 并轮询构建状态。

## 怎么开始

双击 **`start.cmd`**（或在命令行里 `python scripts\serve.py`），
它会起一个只监听 127.0.0.1:8123 的小服务并用 Edge 打开 <http://127.0.0.1:8123/>。

> 不要直接双击 `index.html`：浏览器会对 `file://` 下的 `fetch('data/*.json')` 报跨域错误。
> 已经在跑服务时再执行 `start.cmd` 会提示端口被占用，直接用浏览器访问即可。

## 里面有什么

- **首页**：18 章总览、每章集数与时长、整体观看进度；侧栏按章折叠展开 80 集。
- **章节页**（`#/chapter/1`）三块内容，对应原书每章的三个部分：
  - **复习笔记**：从 PDF 抽取的正文，插图按原页配回去，带「本章目录」快速跳转；
    小标题下面夹着**视频知识点卡片**（见下），顶部有「只看视频补充」按钮，可一键过滤成纯知识点模式；
  - **课后习题**：每道题一张卡片，图、题干先看，答案与详解默认收起（自己先做）；
  - **考研真题**：按「选择 / 填空 / 判断 / 计算」分组，答案与解析同样折叠。
  - 页面顶部与每节开头都有「打开原书 p.N」，直接在 Edge 内置阅读器里翻到对应页对照公式与图形。
- **公式渲染**：PDF 里的公式被抽平成行内字符（`uC（0＋）＝ 6V`、`i2＝ 2＋5cos(10t＋30°)A`），
  站点用内置的 [KaTeX](https://katex.org/) 在浏览器里把它们重新排版成数学式（上下标、希腊字母、根号、积分区间等）；
  原本以**图片**形式存在的公式一律不动，照原样显示。
  - 覆盖章节笔记、课后习题、考研真题、知识点卡片与**全站搜索结果**；字幕保持纯文本。
  - 猜错时不影响阅读：识别不出的片段保留原样，KaTeX 渲染失败也不会把页面搞崩。
  - 只依赖 `vendor/katex/` 里的本地文件（无 CDN、无外网请求），断网也能用。
- **视频知识点**：把 80 集字幕里老师反复强调的结论、推论、易错点、公式和解题技巧抽出来，
  按内容归到对应章节笔记的小标题下；卡片上标了类型（结论 / 推论 / 注意 / 公式 / 技巧）和出处时间。
  - 视频页底部有「📺 本集讲到的 N 个知识点」，点条目反查笔记里对应的卡片；
  - 全站搜索可以只搜知识点。
- **视频截图卡片**：除了字幕，还按「每 20 帧」从视频画面里抽帧（77 集共 2,110 帧），
  把老师板书上被框起来、标红、写着「注意 / 结论 / 小结」的页面挑出来，做成**截图卡片**，
  按内容归到对应小节下（卡片右上角标「视频截图」，点图可看大图）。
  - 卡片只显示「类型 + 标题 + 截图 + 出处」；OCR 转写的文字不显示在页面上，只用于全站搜索。
  - 同标题、同画面、以及画面近似（8×8 dHash 差 ≤6）的卡片会被去重，只保留一张。
  - 截图只取自本章视频；画面里公式以**截图本身**为准，OCR 文字可能有识别错字。
- **视频页**（`#/video/34`）：左侧 B 站播放器内嵌，右侧 AI 字幕逐句列表。
  - 点任意一句 → 播放器跳到该句时间点（`#/video/34?t=600` 这种带时间的链接可以直接分享）；
  - 字幕里独立搜索、一键复制全文、下载 TXT；
  - 「标记为已看 / 收藏」、上一集 / 下一集，键盘 ← → 也能切集。
- **全站搜索**（`#/search?q=参考方向`）：一次搜笔记、视频知识点、习题、考研真题和**全部视频字幕**，
  结果标明章节与页码；字幕结果点进去直接定位到那一句，知识点结果点进去落到笔记里的卡片。
- **进度与笔记**：观看状态、收藏、每章笔记都存在浏览器 localStorage（不上传任何地方）。
- **笔记贴图（图片在文字中间）**：每章笔记区是可直接编辑的富文本——`Ctrl+V` 粘贴截图、
  把图片拖进编辑框、或点「🖼 在光标处插入图片」选文件，图片就**插在光标所在的位置**，
  夹在文字之间，可以继续在图片上下写字；图片会自动压缩到长边 1500 px 存进浏览器 IndexedDB
  （不上传、关闭页面也不丢），点图看大图，点右上角 × 删除。
- **笔记编辑框随内容长**：编辑区没有固定高度，写多少行、插多少张图就自动撑到多高，
  页面整体滚动，不会出现小块内滚动条。
- **主题与字号**：顶栏右上角 ◐ 切换浅色 / 深色（含 `theme-color`，手机上也跟着变），
  A− / A+ 八档调正文大小 `0.8 / 0.9 / 1 / 1.15 / 1.3 / 1.45 / 1.6 / 1.75` 倍
  （以 `--fs` 变量缩放，插图与卡片一起缩放；1.75 倍时正文约 28.9 px），两项设置都会记住。
  字数太长的行内公式（KaTeX）在窄屏或大字号下会在自己那一行内横向滚动，不会把整页撑宽。
- **手机端**：≤900 px 时侧栏收成抽屉（左上角 ☰ 打开，点旁边灰色遮罩或向左滑关闭），
  正文单列、表格与代码块可横向滚动、按钮栅格化成一行三个，加/减字号只影响可读文本。
- **编辑原文（调试开关）**：顶栏 ✎ 打开后可点正文任意段落直接改写（笔记正文、小标题、公式行、
  图注、知识点卡片、习题与真题的题面/答案都能改）。编辑期间公式按原始文本显示，退出后自动重新排版。
  底部工具条提供**撤销 / 恢复各 15 步**（一次连续输入算一步，`Ctrl+Z` / `Ctrl+Shift+Z` 同效），
  以及**复原全部**（连点两次确认，清空所有改动并一并清掉撤销记录，两者不会互相干扰）。
  改过的段落左侧有一道细色条标记；改动只存在本机浏览器里，不会写回 `data/` 下的 JSON。

## 重新生成数据

```bat
scripts\rebuild.cmd
```

单个脚本的用法：

```bat
python scripts\extract_pdf.py          :: 重新解析原书（约 2 分钟，会重写 data/content 与 data/img）
python scripts\fetch_videos.py         :: 刷新合集信息（80 集、时长、章节归属）
python scripts\fetch_subs.py           :: 只补齐缺的字幕；--force 全量重抓；--page 1 单集自检
python scripts\kp_mine.py              :: 从字幕里挖知识点候选句（--stats 只看统计）
python scripts\kp_prompt.py            :: 生成每章的归纳提示词（data\kp\prompt\chNN.md）
python scripts\kp_merge.py             :: 把 data\kp\raw\chNN.json 合并进笔记；--check 只体检；可带章号
python scripts\build_search.py         :: 重建搜索索引（改完其他脚本后必须跑）
```

### 知识点是怎么来的

1. `kp_mine.py` 用「结论 / 一定注意 / 记住 / 本质 / 推广 / 易错 …」这类提示词给全部 13.7 万句字幕打分，
   取前后文合并成窗口，每章约 40–125 段、约 6k–16k 字（`data/kp/candidates/`）。
2. `kp_prompt.py` 把候选片段连同该章的小标题清单做成提示词，交给大模型按固定 JSON 规格归纳
   （每条要 kind、标题、正文、所属小标题、出处集号与秒数），结果存 `data/kp/raw/chNN.json`。
3. `kp_merge.py` 做四件事：字段与字数校验 → 相似度去重 → 按小标题匹配锚点 → 把卡片 HTML 插到对应标题后面
   （匹配不上的归到章末「视频补充结论」一节）。它先剥离旧卡片再插入，**可以反复跑，结果一致**。
4. `build_search.py` 再把卡片抽成 `k:"kp"` 的搜索条目。

> 第 2 步需要模型参与，`rebuild.cmd` 不会重做归纳，只重跑其余环节；换章重做归纳时，
> 改 `data/kp/raw/chNN.json` 再执行 `python scripts\kp_merge.py N` 即可。

### 关于字幕抓取

B 站的 AI 字幕接口要求**登录态**（`need_login_subtitle`），且字幕地址带 `auth_key`，
所以本站的字幕是用 DSH 浏览器（`C:\Users\TomTomas\AppData\Local\dsh-computer-use-win\agent-browser\kept-edge`，
保留登录态的 Edge）抓的：脚本读该 profile 的 `DevToolsActivePort` 连 CDP，
在 `bilibili.com` 页面里 `fetch(..., {credentials:'include'})`，
**cookies 不出浏览器、不进聊天记录**。要重新抓字幕，先确认那个 Edge 窗口里 B 站是登录状态、
且浏览器正在运行；否则 `fetch_subs.py` 会报连不上 CDP 或 `need_login_subtitle`。

## 已知限制

- **三集没有 AI 字幕**：P06、P17、P56 是 B 站侧就没有字幕（不是登录问题），
  这些集的字幕面板会给出提示并引导去看本章笔记。
- **公式排版是「猜」出来的**：KaTeX 只能还原 PDF 抽平时留下的线索（字母、数字、运算符），
  原文真正写成上标的指数（`22` 其实是 2²）、下标里的中文说明（「电容」）无法可靠还原，个别地方会排错；
  以图片给出的公式不受影响。需要绝对准确的式子时点「原书 p.N」。
  目前已覆盖的写法：端口/电极下标（`UAB`→U_AB、`UN′N`、`uC`、`IL`）、导数（`i=Cdu/dt`、
  `diL(t)/dt` → 分式）、根号（`根号3`、`√3`、`1/根号2`、`√（a2＋b2）`）、组合点（`U̇`）、
  双撇号（`I″`）与希腊字母；公式渲染前会跳过 `figure`，所以图片里的式子不会被二次加工。
- **PDF 页码**：站内页码用的是 `books/notes.pdf` 的页序（与阅读器 `#page=N` 一致），
  与该书印刷页码可能相差几页。
- 极少数图片在原页上被文字压住，抽取后可能和相邻的图注差一位；以原书页为准。
- **笔记图片只在本机**：图片存在浏览器的 IndexedDB 里，换设备、换浏览器或清理站点数据都会丢；
  文字笔记同理（localStorage）。想长期保存请自行导出。
  从旧版本升级时，原先单独列在下面的图片会自动接回笔记正文末尾，不会丢图。
- **视频截图卡片只看图**：页面不再显示 OCR 正文（只用于搜索），板书字迹、手写标注、公式符号
  以截图为准；需要精读时点「原书 p.N」。
- **去重规则**：`scripts/vf_cards.py` 生成时会丢弃重复标题、重复帧、画面近似的候选，
  丢弃明细写在 `data/kp/dedupe_report.json`。
- **人工删除的截图卡**：想删掉某张卡时，把「章号 + 帧文件名」加进 `data/kp/visual_drop.json`，
  再跑 `python scripts/kp_merge_visual.py` 即可（`vf_cards.py` 也会跳过它，重跑不会复活）。
  `_frames/`（2,110 张原始帧 + OCR 中间产物，约 200 MB）不入库，仓库只保留被引用的 195 张。
- **「编辑原文」的改动同样只在本机**：它改的是显示层（localStorage 里的 `edits`），
  不会写回 `data/content/*.json`，所以换设备/清站点数据就没了；想固化请改数据文件后重跑脚本。
  撤销记录只保留 15 步，刷新页面后撤销栈会清空（改动仍在），只有「复原全部」能一次性回到原始文本。
- **考研真题里的少数答案仍会露出来**：原书的答案有时不以「【答案】/【解析】/解：」标记，
  程序只能折叠带标记或紧跟答案的段落，个别计算题的中间过程仍会显示在题干下面。
- **知识点是「归纳」而不是原文**：每条都标注了出处集号与时间，但表述经过压缩与改写，
  只有点开对应视频时间点才能听到老师原话；三集无字幕的课（P06/P17/P56）内容也会有部分覆盖不到。
  知识点的分类（结论/推论/注意/公式/技巧）由模型给出，偶尔会有归类偏差。
